# instagram-agent-he

13 סקילים ל-Claude שמנהלים חשבון אינסטגרם אחד של עורך דין, סופר ומרצה, בעברית
ובתוך כללי הפרסומת של לשכת עורכי הדין.

גרסה מותאמת של [instagram-agent](https://github.com/nategoldai/instagram-agent)
(במקור של Jake Schincariol, [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)),
רישיון MIT. זו התאמה, לא תרגום: מה שעובד נשאר, ומה שלא מתאים לעורך דין ישראלי
הוחלף.

**שום דבר לא עולה לאוויר בלי "כן" שלך.** הסקילים כותבים. אתה מפרסם.

## התקנה

**ב-claude.ai (דפדפן, דסקטופ, טלפון):** פתח את הקובץ `instagram-agent-he.plugin`
בשיחה ולחץ על כפתור ההתקנה. אם הכפתור לא מופיע: Customize > Plugins > Add, והעלה
את הקובץ. צריך שהרצת קוד תהיה פעילה (Settings > Capabilities).

**ב-Claude Code במק:** פתח את `instagram-agent-he.zip`, ואז בתוך Claude Code:

```
/plugin marketplace add ~/Downloads/instagram-agent-he
/plugin install instagram-agent-he@instagram-agent-he
```

**גיבוי, אם התקנת הפלאגין נכשלת:** יש קובץ ZIP נפרד לכל סקיל (`dist/claude-ai-skills/`),
להעלאה דרך Customize > Skills, אחד אחד.

## לפני השימוש הראשון

1. **`voice.md`** - הקול שלך. חלק כבר מולא, ומה שמסומן `{{...}}` עוד לא. הדרך
   הקלה: שלח ל-Claude שלושה רילס או כיתובים שלך ותגיד "תעדכן את voice.md לפי אלה".
   ב-claude.ai: צור Project בשם "אינסטגרם" ושמור בו את `voice.md` המעודכן. הסקילים
   קוראים אותו משם, והוא גובר על הגרסה שבתוך הפלאגין. באותו Project כדאי לשמור גם
   את `plan.md`, `swipe.md`, `log.md` ו-`archive.md`.
2. **הקצב שלך** - קרא בקול תסריט של 100 מילים עם סטופר ורשום ב-`voice.md` כמה
   מילים לדקה יצא. בלי זה, התזמון של הרילס מניח 140 מילים לדקה, וזו הערכה.
3. **הדומיין של דף הנחיתה** - עד שהוא נרשם ב-`ethics.json` (`allowed_domains`),
   כל קישור יקבל REVIEW. תגיד ל-Claude מה הדומיין והוא יעדכן.

## שכבת הציות

`compliance.md` מסכם את הכללים שחלים על פרסום של עורך דין: כללי הפרסומת
(התשס"א-2000, כולל תיקון 2018), גילוי הדעת של ועדת האתיקה הארצית על סרטונים
ברשתות (9.8.2026), איסור השידול, חובת הסודיות ואיסורי הפרסום בענייני משפחה. 23
כללים עם קודים C1-C23, ולכל אחד מקור.

`ethics.py` בודק כל טקסט לפני שהוא מגיע אליך: סופרלטיבים, "מומחה", הבטחת תוצאה,
סכומים שנפסקו, סיפורי לקוחות, שכר טרחה ו"חינם", הזמנות לפרטי, אפקטים ושירים
בסרטון, השלמות שלא מולאו. FAIL מתוקן לפני שאתה רואה. REVIEW מוצג לך עם הקוד,
ואתה מחליט.

**מה זה לא:** זה לינטר של ביטויים, לא חוות דעת. הוא לא יודע אם יש הסכמה בכתב, מי
פנה ראשון או מה רואים בסרטון. ריצה נקייה אומרת שלא נמצא משהו שאפשר לזהות בטקסט,
לא שהפרסום תקין. חלק מהכללים מסומנים [פרשנות] או [לא אומת], והאחריות על כל פרסום
נשארת שלך (C18).

## מגבלות, ביושר

- **הציון של ההוק בעברית** מכויל לפי אותו היגיון כמו באנגלית, עם התאמה לכך
  שבעברית יש בערך 17% פחות מילים לאותו משפט. זו היוריסטיקה. גם במקור, הכלי טוב
  בלפסול הוקים חלשים ולא בלבחור מנצח. את הסיבוב השני מכריע גרף הצפייה שלך.
- **140 מילים לדקה** הוא ברירת מחדל עד שתמדוד את עצמך.
- **הסקילים לא מפרסמים לאינסטגרם**, לא מתחברים לחשבון ולא מבקשים סיסמה.
- **מספרים של הפלטפורמה מתיישנים.** מגבלת 5 ההאשטגים נכנסה ב-18.12.2025. אם משהו
  כאן סותר את מה שאינסטגרם עושה כשאתה קורא, אינסטגרם צודקת.
- **הכללים צפויים להשתנות.** לפי דיווח מאוגוסט 2026, בלשכה מנסחים כללים חדשים
  לפרסום ברשתות. כשהם יפורסמו, `compliance.md` ו-`ethics.json` צריכים עדכון.

## עריכה

המקור נמצא ב-`shared/` (הקול, ההקשר, הכללים והכלים) וב-`skills/ig-*/SKILL.md`. אחרי
שינוי, `python3 build.py` מעתיק את הקבצים המשותפים לכל סקיל, בודק, ואורז מחדש.
`python3 tests/run_tests.py` מריץ 46 בדיקות בעברית ובאנגלית.
